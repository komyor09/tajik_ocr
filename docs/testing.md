# Тестирование и качество

## Юнит-тесты

```powershell
uv run pytest -q
```

Тесты не требуют изображений и работают на вымышленных данных: разбор MRZ (образец из ICAO 9303),
транслитерация и исправление ФИО, словарь адресов, маппинг анкеты HR, оценки и `needs_review`.
Запускаются в GitHub Actions при каждом пуше (`.github/workflows/tests.yml`).

## Вымышленные образцы карт

Реальные паспорта в репозиторий не попадают. Для сквозной проверки есть генератор образцов:
вымышленные ФИО, даты, номера, адреса по реальным районам, MRZ с правильными контрольными цифрами,
серый силуэт вместо фото и надпись **«НАМУНА · SPECIMEN»** поперёк карты.

```powershell
uv run python scripts/make_specimens.py -n 30                 # ровные «сканы»
uv run python scripts/make_specimens.py -n 30 --photo --seed 5 # «фото телефоном»: фон, наклон, перспектива, размытие, JPEG
uv run python scripts/eval_specimens.py                        # прогон через /hr/passport и сравнение с truth.json
uv run python scripts/eval_specimens.py --lang en -v           # английский, с выводом каждой ошибки
```

Образцы пишутся в `samples/specimens/` (папка в `.gitignore`). Отчёт показывает по каждому полю:
сколько верно, сколько ошибок **не попало** в `needs_review` (главный показатель — должно быть 0)
и сколько верных полей помечено зря.

## Результаты (v0.4)

Вымышленные образцы, `/hr/passport`, 12 сравниваемых полей на карту:

| Набор | `tg` | `en` | Ошибок без пометки | Зря помечено |
|---|---|---|---|---|
| 20 «сканов» | 240/240 (100%) | 240/240 (100%) | 0 | 5 из 240 (2%) |
| 30 «фото» (новый набор, не использовался при настройке) | 327/360 (90,8%) | 332/360 (92,2%) | 0 | 32 из 360 (9%) |

На «фото» ФИО, пол, даты, личный номер и номер документа — 28–30 из 30. Больше всего ошибок
у РМА/ИНН (мелкий шрифт под водяным знаком) и у частей адреса; все они попадают в `needs_review`.

Реальные ID-карты (3 шт., сканы и фото телефоном, проверено в v0.3 до удаления сканов из проекта):
57/57 полей; 21 имитация фото, сделанная из них, — 98,5% ключевых полей. На этих картах система
настраивалась, поэтому это не независимая оценка.

**Что нужно для честной оценки:** 20–30 реальных карт разных людей (женщины, длинные ФИО,
разные регионы, потёртые карты, блики) — с согласием владельцев, локально, вне git.
Добавьте их в `samples/real/` со своим `truth.json` того же формата, что у генератора, и запустите
`scripts/eval_specimens.py samples/real`.
