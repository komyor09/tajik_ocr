# Персональные данные

Паспортные данные — персональные данные. Правила проекта:

**В сервисе**
- Изображения не сохраняются. Загрузки больше 1 МБ FastAPI временно держит в `/tmp` до конца
  запроса — в Docker смонтируйте `/tmp` как `tmpfs` (см. DEPLOY.md), тогда они не попадают на диск.
- Распознанные данные не логируются; в логах uvicorn остаются только пути и коды ответов.
- Сервис внутренний: доступ только из локальной сети через nginx; ключ доступа не используется.
- Данные никуда не отправляются: всё распознавание выполняется локально, без внешних сервисов.

**В репозитории**
- Ни одного реального документа: эталоны `app/passport/templates/` обезличены (фото, ФИО, даты,
  номера, подпись, MRZ стёрты — остались только дизайн карты и подписи полей).
- Тесты, примеры в документации и образцы генератора используют вымышленные данные.
- `samples/`, все `*.jpg`/`*.jpeg` и `.env` исключены через `.gitignore`.
- Перед публикацией проверьте индекс: `git ls-files` не должен содержать сканов,
  `git grep` — реальных ФИО и номеров.

**При тестировании на реальных картах**
- Только с согласия владельцев (короткое письменное согласие: цель — тестирование, данные не
  передаются третьим лицам).
- Сканы — локально в `samples/`, удалять после проверки.
- Не использовать для разработки документы, собранные для других целей (например, сканы
  абитуриентов или сотрудников из рабочих систем), без отдельного правового основания.
